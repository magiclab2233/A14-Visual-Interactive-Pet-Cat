# A14 视觉交互智能宠物猫

基于树莓派（Raspberry Pi）与视觉表情识别技术的智能互动机器猫。当摄像头捕捉到用户笑容时，机器猫会自动挥动手臂回应，实现有趣且自然的人机交互体验。

---

## 项目简介

本项目是 **InnoFlow 青少年 AI 创意项目** 之一，旨在通过低成本的树莓派硬件平台，结合计算机视觉与物理控制技术，打造一个能“看懂”人类表情并做出反馈的智能宠物猫。系统利用摄像头实时采集画面，通过人脸表情识别判断用户是否露出笑容，一旦检测到“开心（happy）”表情，即刻驱动舵机带动机器猫手臂挥动，传递温暖与趣味。

项目兼具 **趣味性** 与 **教育意义**，适合作为青少年学习人工智能、物联网（IoT）和嵌入式开发的实践案例。

---

## 功能特点

- **实时笑容检测**：通过摄像头持续捕捉画面，利用 AI 人脸表情识别技术实时判断用户情绪状态。
- **即时物理反馈**：检测到笑容后，机器猫手臂会在数百毫秒内完成一次自然挥动动作，实现“所见即所动”的交互体验。
- **轻量高效**：针对树莓派硬件进行优化，采用后台线程异步处理识别任务，主线程保持画面流畅采集与显示。
- **平滑舵机控制**：自定义 PWM 脉冲驱动，支持慢速平滑转动，避免舵机抖动，延长机械结构寿命。
- **简单易部署**：代码结构清晰，依赖精简，只需安装少量 Python 包即可运行。

## 技术架构与实现原理

### 硬件架构

| 组件 | 说明 |
|------|------|
| **树莓派** | 主控板（Raspberry Pi），运行 Raspberry Pi OS |
| **摄像头** | 连接树莓派的 CSI/USB 摄像头，用于实时视频采集 |
| **SG90 舵机** | 微型舵机，负责驱动机器猫的手臂结构 |
| **机器猫模型** | 包含机械手臂的 3D 打印或拼装模型 |

### 软件架构

系统采用 **多线程** 设计，分为两条核心流程：

1. **主线程（视频采集）**：
   - 使用 `picamera2` 库初始化并配置摄像头（分辨率 640×480，RGB888 格式）。
   - 以循环方式实时捕获画面帧，并通过 `cv2.imshow` 在本地窗口显示。
   - 将最新帧写入线程安全的共享变量 `latest_frame`，供识别线程读取。

2. **识别线程（表情分析）**：
   - 守护线程每 1 秒从共享变量中复制最新帧，保存为本地图片 `latest.jpg`。
   - 调用 `api.py` 中的 `facial_expression()` 函数，将图片上传至 AI 表情识别服务，获取画面的主导情绪（dominant emotion）。
   - 若识别结果为 **`happy`**，则触发 `servo_control_slow()` 驱动舵机挥臂；否则保持静止并继续监测。

### 舵机控制原理

- 采用 **软件模拟 PWM** 方式，通过 `RPi.GPIO` 控制 GPIO12（BCM 编码）引脚。
- 舵机时基脉冲为 **20 ms**，高电平宽度在 **0.5 ms ~ 2.5 ms** 之间对应 **0° ~ 180°**。
- `servo_move_slow()` 函数以微步进（step=1°）和延时（delay=0.05 s）实现平滑转动，避免瞬间大角度跳转带来的机械冲击。
- 触发一次完整的交互动作：舵机从 **0° 缓慢转动到 25°，再缓慢回到 0°**。

## 项目目录结构

```
A14-视觉交互智能宠物猫/
├── README.md              # 项目说明文档
├── requirements.txt       # Python 依赖（picamera2）
├── .gitignore             # Git 忽略规则
├── face.py                # 主程序：摄像头采集 + 表情识别线程调度
├── api.py                 # 表情识别 API 封装（调用远程人脸表情分析服务）
└── servo.py               # 舵机控制模块（GPIO 初始化、PWM 脉冲、平滑转动）
```

### 文件说明

- **`face.py`**：程序入口。负责初始化 `Picamera2`，启动后台识别线程，并在检测到 `happy` 表情时调用舵机控制函数。
- **`servo.py`**：底层硬件控制。包含 `servo_control_slow()` 等函数，用于安全、平滑地驱动 SG90 舵机。

## 安装与运行说明

### 1. 硬件准备

- 树莓派（建议 Raspberry Pi 4 或更新版本）
- 树莓派摄像头模块（CSI 接口）
- SG90 微型舵机 × 1
- 机器猫模型及机械手臂结构
- 杜邦线若干（舵机信号线接 GPIO12）

> **接线提示**：舵机信号线（黄色/橙色）连接树莓派 **GPIO12（BCM 编码，对应物理引脚 32）**，电源线接 5V，地线接 GND。

### 2. 软件环境

- 安装 [Raspberry Pi OS](https://www.raspberrypi.com/software/)
- 确保系统已启用摄像头接口（`raspi-config` → Interface Options → Camera → Enable）
- 确保树莓派已连接互联网（用于调用远程表情识别 API）

### 3. 安装依赖

在项目目录下打开终端，执行：

```bash
pip install -r requirements.txt
```

> `requirements.txt` 中默认包含 `picamera2==0.3.25`。若运行环境还需要 `opencv-python`、`requests`、`RPi.GPIO`，请根据系统环境自行补充安装。

### 4. 运行项目

```bash
python3 face.py
```

程序启动后：
- 会自动打开摄像头预览窗口（标题为 `Full FOV Video`）。
- 每秒钟后台会对当前画面进行一次表情分析。
- 当你对摄像头露出笑容时，机器猫的手臂就会挥动起来！
- 按键盘 **`q`** 键退出程序。

### 5. 常见问题

- **摄像头无法打开**：检查摄像头排线是否插紧，并在 `raspi-config` 中确认摄像头已启用。
- **舵机不转动**：确认 GPIO 接线正确，且当前用户拥有 GPIO 操作权限（通常需要 `root` 或在 `gpio` 用户组内）。
- **表情识别返回错误**：检查网络连接，确保能访问远程 API 地址。
